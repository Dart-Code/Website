# v3.140.0 _2026-08-03_

## Flutter

- [#5844](https://github.com/Dart-Code/Dart-Code/issues/5844)/[#4607](https://github.com/Dart-Code/Dart-Code/issues/4607)/[#6109](https://github.com/Dart-Code/Dart-Code/issues/6109): Flutter SDKs from `PATH` now take priority over those found from a `.dart_tool/package_config.json` file.

## Editor

- [#6118](https://github.com/Dart-Code/Dart-Code/issues/6118)/[#6135](https://github.com/Dart-Code/Dart-Code/issues/6135): A new command **Dart: Toggle Show TODOs** toggles the `dart.showTodos` setting, allowing TODOs to be quickly shown or hidden.
- [#6130](https://github.com/Dart-Code/Dart-Code/issues/6130)/[#6132](https://github.com/Dart-Code/Dart-Code/issues/6132): The TextMate grammar used to provide initial syntax highlighting until the server provides Semantic Tokens has been updated to handle unclosed triple-backtick code blocks in dartdoc comments.
- [#6120](https://github.com/Dart-Code/Dart-Code/issues/6120)/[#6121](https://github.com/Dart-Code/Dart-Code/issues/6121): Code actions that make multiline replacements will no longer sometimes end up with additional indentation.

## Testing

- [#5967](https://github.com/Dart-Code/Dart-Code/issues/5967): When using `package:test_reflective_loader`, class-wide setUp/tearDown methods no longer appear on all classes, whether they exist or not (requires an upcoming release of `package:test_reflective_loader`).
- [#5950](https://github.com/Dart-Code/Dart-Code/issues/5950): When using `package:test_reflective_loader`, class-wide setUp/tearDown methods in the test explorer now navigate to those methods instead of the `defineReflectiveSuite` call (requires an upcoming release of `package:test_reflective_loader`).

## Commands

- [#6122](https://github.com/Dart-Code/Dart-Code/issues/6122)/[#6123](https://github.com/Dart-Code/Dart-Code/issues/6123): The **Dart: New Project** and **Flutter: New Project** commands have been renamed to **Dart: Create New Project** and **Flutter: Create New Project** so that they are included in the results when searching the command palette for `dart create` and `flutter create`.

## Misc

- [#6111](https://github.com/Dart-Code/Dart-Code/issues/6111): Due to the [sunsetting of Firebase Studio](https://firebase.google.com/docs/studio/migrating-project), support for using the extension on Firebase Studio is deprecated and will be removed in an upcoming extension release.
- [#6117](https://github.com/Dart-Code/Dart-Code/issues/6117): A clearer error notification is now shown when the Dart anlaysis server fails to start due to the current version of macOS being unsupported.
- [#6131](https://github.com/Dart-Code/Dart-Code/issues/6131): Automated tests for the TextMate grammar in the Dart-Code repository and the dart-syntax-highlight repository are now aligned and produce the same output for the same grammar/input.
- [#6129](https://github.com/Dart-Code/Dart-Code/issues/6129): TextMate grammar tests now run on the GitHub bots.

## Features/Fixes Enabled with Future SDKs

The following items depend on changes to the Dart/Flutter SDKs that have not yet been released to stable channels. They may be available to test in the current beta/master channels and will show up in future SDK releases.

- [#6054](https://github.com/Dart-Code/Dart-Code/issues/6054)/[#6059](https://github.com/Dart-Code/Dart-Code/issues/6059)/[#6077](https://github.com/Dart-Code/Dart-Code/issues/6077)/[#6107](https://github.com/Dart-Code/Dart-Code/issues/6107)/[#6098](https://github.com/Dart-Code/Dart-Code/issues/6098): A new mechanism has been added to allow refactors to collect user input. The first refactors to use this are "Add a name to the constructor" and "Add a prefix to the import" which will now prompt for the name rather than using a server-generated default name.
- [#5066](https://github.com/Dart-Code/Dart-Code/issues/5066)/[#6082](https://github.com/Dart-Code/Dart-Code/issues/6082): The "Move to File" refactor been updated to use an improve file picker to avoid misleading overwrite prompts.
- [#6115](https://github.com/Dart-Code/Dart-Code/issues/6115): The analysis server no longer sometimes crashes if it's open while the Dart SDK is overwritten (for example by a Flutter update).
- [#6112](https://github.com/Dart-Code/Dart-Code/issues/6112): Code blocks in dartdocs no longer lose their colouring when the TextMate grammar is replaced by server-provided Semantic Tokens.
- [#6017](https://github.com/Dart-Code/Dart-Code/issues/6017): The Flutter Widget Preview show no longer show an infinite loading status when it has fatally errored.
- [#5839](https://github.com/Dart-Code/Dart-Code/issues/5839): `test()` and `group()` calls now show closing labels next to their closing parentheses.
