# v3.144.0 _2026-09-??_

## Flutter

- [#6179](https://github.com/Dart-Code/Dart-Code/issues/6179)/[#6190](https://github.com/Dart-Code/Dart-Code/issues/6190): Flutter icon previews no longer fail to show in code completion documentation when it is fetched lazily from the analysis server.
- [#6178](https://github.com/Dart-Code/Dart-Code/issues/6178): Attempting to open DevTools pages when running a Wasm build now shows a more helpful message about not being supported, rather than saying the debug session is not ready yet.

## Editor

- [#6164](https://github.com/Dart-Code/Dart-Code/issues/6164)/[#6175](https://github.com/Dart-Code/Dart-Code/issues/6175): The "Move Top Level" refactor now uses a better default directory when creating a new file.
- [#6189](https://github.com/Dart-Code/Dart-Code/issues/6189)/[#6197](https://github.com/Dart-Code/Dart-Code/issues/6197): The TextMate grammar was updated to support fenced code blocks using more than 3 backticks, allowing for triple-backticks to appear within a codeblock without ending it.
- [#6177](https://github.com/Dart-Code/Dart-Code/issues/6177): The TextMate grammar was updated to match Dartdoc and the analysis server requiring 4 spaces to indent a non-fenced code block _in addition to_ the space separating the comment markers.

## Debugging

- [#6114](https://github.com/Dart-Code/Dart-Code/issues/6114)/[#6196](https://github.com/Dart-Code/Dart-Code/issues/6196): A new setting `dart.defaultExceptionPauseMode` allows setting the default exception pause mode for new workspaces. VS Code persists the selection in each workspace, but a new workspace (or Git worktree) previously would always default to pausing on Uncaught exceptions.

## Testing

- [#5716](https://github.com/Dart-Code/Dart-Code/issues/5716)/[#6191](https://github.com/Dart-Code/Dart-Code/issues/6191): A new option `"auto"` has been added to the `dart.testInvocationMode` setting which tries to pick between using line numbers or test names when running tests depending on the situation. Running by name can fail for tests/groups with dynamic names that might not be computed correctly statically, but running by line number can fail for unsaved files which get formatted-on-save as the test run starts.

## Commands

- [#6182](https://github.com/Dart-Code/Dart-Code/issues/6182): The "Add SDK to PATH" command on Linux now uses `~/.bashrc` instead of `~/.bash_profile` (which is still used on macOS).
- [#6159](https://github.com/Dart-Code/Dart-Code/issues/6159)/[#6160](https://github.com/Dart-Code/Dart-Code/issues/6160): [@10xtushar](https://github.com/10xtushar) contributed a fix to open Xcode by bundle ID rather than app name to support `Xcode-beta.app`.

## Misc

- [#6183](https://github.com/Dart-Code/Dart-Code/issues/6183): Antigravity CI bots were updated to use the new Antigravity IDE version on Windows.
- [#6195](https://github.com/Dart-Code/Dart-Code/issues/6195)/[#6192](https://github.com/Dart-Code/Dart-Code/issues/6192)/[#6187](https://github.com/Dart-Code/Dart-Code/issues/6187)/[#6174](https://github.com/Dart-Code/Dart-Code/issues/6174)/[#6172](https://github.com/Dart-Code/Dart-Code/issues/6172)/[#6171](https://github.com/Dart-Code/Dart-Code/issues/6171)/[#6170](https://github.com/Dart-Code/Dart-Code/issues/6170)/[#6168](https://github.com/Dart-Code/Dart-Code/issues/6168)/[#6167](https://github.com/Dart-Code/Dart-Code/issues/6167)/[#6166](https://github.com/Dart-Code/Dart-Code/issues/6166): Many improvements were made to improve the speed of the Dart-Code automated test runs.

## Features/Fixes Enabled with Future SDKs

The following items depend on changes to the Dart/Flutter SDKs that have not yet been released to stable channels. They may be available to test in the current beta/master channels and will show up in future SDK releases.

- [#6162](https://github.com/Dart-Code/Dart-Code/issues/6162): Link detection in the debug console has been improved for Flutter errors (for links following "The relevant error-causing widget was").
- [#6154](https://github.com/Dart-Code/Dart-Code/issues/6154): Closing block comment markers are no highlighted as code if a fenced code block is not closed.
- [#6081](https://github.com/Dart-Code/Dart-Code/issues/6081): Hovers and code completion now show positional parameter names in many places for function types where they did not before.
